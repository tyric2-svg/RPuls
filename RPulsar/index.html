Добро пожаловать в RPulsar!

1
Ваше рабочее пространство
RPulsar — это современный трекер задач для команд. Организуйте работу, отслеживайте прогресс и ничего не упускайте.
2
Три способа видеть задачи
Переключайтесь между представлениями в зависимости от задачи:
Таблица
Для детальной работы и сортировки
Kanban
Для визуального workflow
Календарь
Для планирования по срокам
3
Работайте быстрее
Используйте горячие клавиши для мгновенного доступа к функциям:
Новая задача C
Редактировать задачу E
Command Palette Ctrl+K
Все горячие клавиши ?
4
Работайте вместе
Подключите общую папку для синхронизации с командой. Все изменения автоматически сохраняются и доступны другим участникам.
